# ai-ime-runo

open-runoシリーズの一員。前後の文脈から変換候補をAIが用意する日本語IME(ひな型段階)。

## 現状(ひな型)でできること

- 種辞書(シードデータ)による読み→変換候補の検索(1つの読みに複数候補も可)
- 変換候補の文字種から、ひらがな/カタカナ/アルファベット入力モードを自動提案
- 変換候補の並べ替えロジックを`ConversionBackend`トレイトとして差し替え可能
  (無料AI・契約AI・オープンソースのローカルLLMへの接続は、この土台の上に
  今後実装する)

### 動作例

| 読み | 変換候補 | 提案モード |
|---|---|---|
| さざんあいず | 3X3 EYES / サザンアイス | Alphabet |
| さんじゃやんうんから | 三只眼吽迦羅 | Hiragana |
| はんにゃしんぎょう | 般若心経 | Hiragana |
